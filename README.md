# Emulsion Engine

Emulsion Engine — это редактор изображений с обучающей презентацией о том, как [фотоэмульсия](https://ru.wikipedia.org/wiki/Фотоэмульсия) превращает вероятность появления зерна в изображение. С его помощью вы получаете интерактивный способ исследовать аналоговую фотографию.

Emulsion Engine показывает, как можно выразить физику фотоплёнки через вероятность. Вероятность появления каждого зернышка задаётся распределением, повторяющим форму [характеристической кривой](https://ru.wikipedia.org/wiki/Характеристическая_кривая), и именно это распределение передаёт изображению яркость, контрастность и цвет.

Это проект для творчества, обучения и визуальных экспериментов. Он подходит как для художественной обработки изображений, так и для демонстрации того, как физические свойства эмульсии влияют на изображение.

## Идея алгоритма

Идея строится вокруг стохастической модели эмульсии. В модели задаётся распределение вероятности появления зерна в зависимости от яркости. Чем выше экспозиция, тем вероятнее появление нового зерна в данном участке изображения.

В общих чертах алгоритм можно представить так:

1. На исходном холсте создается множество объектов-зерен, положение, размер и форма которых заданы случайно. Можно представить, что это виртуальная фотоэмульсия.
2. Экспозиция. Каждое зерно получает вероятность своей активации по формуле распределения вероятностей в зависимости от яркости изображения в той точке, в которой находится зерно.
<img width="640" height="366" alt="image" src="https://github.com/user-attachments/assets/4d2028d6-2111-4ad1-8fce-a3b72b8bd305" />

3. Зерно "активируется" случайно с учетом вычисленной вероятности. На итоговом изображении остаются только активированные зерна.
4. Итоговое изображение складывается из-за симуляции оптической плотности, т.е. плотностью расположения друг к другу полученных зерен, а также складывания их яркости при наложении друг на друга. Изображение сразу создается в позитивном варианте, без промежуточного негатива, поскольку это не имеет смысла для симуляции.
<img width="640" height="432" alt="image" src="https://github.com/user-attachments/assets/50ab8203-c5c2-4bea-98d9-94ef2d900560" />

5. Для получения цветного изображения тот же процесс происходит независимо для каждого канала (R,&nbsp;G,&nbsp;B). При этом сами зерна окрашиваются в соответствующие цвета.

Для каждого зернышка независимо высчитывается вероятность появления, но при этом кривая распределения вероятностей ведет себя именно так, как мы этого ожидаем от характеристической кривой. Именно так в модели проявляется закон больших чисел для вероятности.

## Шейдеры и рендер

Рендер выполняется на GPU пользователя с помощью WebGL2 и фрагментного шейдера.
